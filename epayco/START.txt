┌──────────────────────────────────────────────────────────────────────────┐
│  ❌ PROBLEMAS COMUNES Y SOLUCIONES RÁPIDAS                             │
└──────────────────────────────────────────────────────────────────────────┘

PROBLEMA: Token Status: NO OBTENIDO ✗
CAUSA:    Claves API no configuradas
SOLUCIÓN: Joomla → Extensiones → Plugins → ePayco
          Llenar: Public Key + Private Key
          Guardar

PROBLEMA: No veo logs en la consola
CAUSA:    Consola cerrada o equivocada
SOLUCIÓN: Presiona F12
          Pestaña "Console" (no Elements)
          Recarga página (Ctrl+F5)

PROBLEMA: Se abre popup pero no funciona
CAUSA:    Datos de pago inválidos
SOLUCIÓN: Revisa en consola los datos
          Verifica: amount, currency, country
          Compara con LOGS_EJEMPLOS.md

PROBLEMA: Error CURL [60] SSL
CAUSA:    Problema de certificado
SOLUCIÓN: Verifica conexión a internet
          O contacta hosting
          O ver DEBUG_GUIDE.md
